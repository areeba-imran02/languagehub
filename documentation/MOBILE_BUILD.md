# Mobile builds

The Expo app is a source project only. Run `npm install` and `npx expo start` in `apps/mobile`. Use `npx expo run:android` / `npx expo run:ios` for local native builds where toolchains are installed, or configure EAS Build and signing credentials. No APK or IPA is included or claimed. Microphone permission is declared for future speaking features; recording/transcription flows remain pending.
